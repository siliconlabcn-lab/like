# Like 的项目

本站由 GitHub Pages 从 `main` 分支的根目录发布：

- 首页：<https://siliconlabcn-lab.github.io/like/>
- 主场 · 球星之夜：<https://siliconlabcn-lab.github.io/like/football-game/>

足球游戏来自 [football-game-Like 的已发布版本](https://github.com/siliconlabcn-lab/football-game-Like/tree/5e0bf5e713628eb3c243a43db0560232c4562131)。源仓库的新提交需要同步到本站才会更新新网址。素材来源及许可见 [素材鸣谢](football-game/play-v3/credits.html)。

新增项目时，在仓库根目录为项目创建一个目录，把入口文件命名为 `index.html`，再在首页添加链接。
